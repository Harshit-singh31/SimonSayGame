# Simon Game

This repository contains the implementation of the classic **Simon Game**, a memory-based game where players repeat a sequence of flashing colors and sounds. Each round, the sequence grows longer, challenging the player's ability to recall and reproduce the pattern.

## Features

- Interactive and engaging gameplay.
- Visual and auditory feedback for each step.
- Dynamic generation of random sequences.
- Tracks the highest score achieved by the player.
- Fully responsive design for desktop and mobile devices.

## How to Play

1. Press the "Start" button to begin the game.
2. Watch the sequence of flashing colors and sounds.
3. Repeat the sequence by clicking the color buttons in the correct order.
4. If you succeed, the sequence grows longer. Repeat until you make a mistake.
5. Your score increases with each correct round!

## Installation

To run this game locally, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/Harshit-singh31/simongame.git
   ```

2. Navigate to the project folder:

   ```bash
   cd simongame
   ```

3. Open the `index.html` file in your web browser.

## Usage

Simply open the `index.html` file in any modern browser to start playing the game. No additional installations are required.
